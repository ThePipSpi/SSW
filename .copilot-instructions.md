# Wow Agent Instructions

Welcome to the Wow Agent! This guide will help you become an expert developer for the World of Warcraft Midnight addon (version 120001). Follow these steps to ensure your experience is smooth and successful.

## Step-by-Step Instructions

1. **Setting Up Your Development Environment**  
   a. Download and install the necessary tools.  
   b. Configure your IDE for Lua, the programming language used.  

2. **Creating Your First Addon**  
   a. Identify the purpose of your addon.  
   b. Create a directory in your WoW addons folder.  
   c. Create a `.toc` file with your addon's metadata.  
   ```toc
   ## Interface: 120001
   ## Title: My First Addon
   ## Notes: My first attempt at creating a WoW addon.
   main.lua
   ```  
   d. Write your main Lua script in `main.lua`:  
   ```lua
   function greetPlayer()
       print("Hello, Player!")
   end
   greetPlayer()
   ```  
   e. Reload the game and see your addon in action!  

## Combat Safety

1. Always ensure you test your addon in a safe environment.
2. Use the WoW API functions to handle combat properly and avoid crashing the game.

## Error Handling

1. Implement error handling in your scripts.  
   ```lua
   local success, err = pcall(function() 
       -- your code here
   end)
   if not success then
       print("Error occurred: " .. err)
   end
   ```  

## Debug Messages

1. Use `print()` statements to output debugging information to the console.  
   ```lua
   print("Debug: Your current data here")
   ```  

## Additional Tips

- Read the WoW API documentation for in-depth details about functions.
- Join forums and communities to seek help and share your experiences.
- Always keep your addon updated with the latest WoW versions to avoid incompatibility issues.

By following these guidelines, you'll be well on your way to creating powerful and effective addons for World of Warcraft!
