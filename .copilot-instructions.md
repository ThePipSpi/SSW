# Copilot Instructions for Wow Agent

Welcome to the development of the World of Warcraft Midnight add-on! Below are the complete prompt instructions for using Wow Agent effectively:

## Project Overview
The Midnight add-on enhances the World of Warcraft experience by providing additional features, customization options, and quality-of-life improvements.

## Development Guidelines
1. **Code Structure**: Follow the Model-View-Controller (MVC) pattern to keep your code organized.
2. **Documentation**: Make sure to document your code thoroughly using in-line comments and a dedicated README file.
3. **Version Control**: Utilize branches for new features or bugs. Keep the main branch stable.

## Using Wow Agent for Development
To utilize Wow Agent in your development process, follow these steps:
1. **Setup**: Ensure that WOW environment variables are set correctly.
2. **Prompt Template**: Use this prompt for your interactions:
   - "Hey Wow Agent, I need help with [specific development task]. Here are the current features of the add-on [list features]. I want to [describe desired enhancements or bug fixes]."
3. **Feedback Loop**: After receiving guidance from Wow Agent, apply the suggestions in your code and test thoroughly.
4. **Iterate**: Continue to ask for assistance as you progress with different features.

## Common Workflow Commands
- **Create New Feature**: If you are starting a new feature, document it first and present it to Wow Agent.
- **Debugging**: Clearly specify the bug and share relevant snippets of the code.

## Conclusion
Using Wow Agent can greatly assist in speeding up the development process. Don’t hesitate to explore its capabilities as you enhance the Midnight add-on.
